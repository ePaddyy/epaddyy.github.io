# epaddyy.github.io

Portfolio site of **Emmanuel Paddy Adams**, Machine Learning Engineer in Accra, Ghana.
Built with [Astro](https://astro.build), deployed to GitHub Pages by GitHub Actions.

**Live:** https://epaddyy.github.io

## Quick start

Requires Node.js 24 (see `.nvmrc`).

```sh
npm install        # once
npm run dev        # http://localhost:4321, reloads as you edit
```

| Command           | What it does                                                  |
| ----------------- | ------------------------------------------------------------- |
| `npm run dev`     | Local dev server with hot reload. Drafts are visible here.    |
| `npm run build`   | Production build into `dist/` (validates all content first)   |
| `npm run preview` | Serve the production build locally (use this to test the CSP) |
| `npm run check`   | Type-check `.astro` and `.ts` files                           |
| `npm run format`  | Format everything with Prettier                               |
| `npm run verify`  | Everything CI runs: format check, type check, build           |

You never upload anything by hand: **push to `main` and the site deploys itself.**

## Where things live

```
├── content/               ALL content, as Markdown
│   ├── projects/          one file per project → card on /projects/ (+ /projects/<file>/ if it has a case study)

│   ├── education/
│   ├── certifications/
│   └── writing/           articles (draft: true = hidden in production)

├── components/            Header, Footer, ProjectCard, TimelineItem, Stats, Photo, ContactForm, SEO, Icon
├── layouts/BaseLayout.astro
├── pages/                 file = URL (index, projects/, projects/[slug], writing/, 404, og images, robots.txt)
├── lib/                   content helpers, icon set, social-image renderer
├── scripts/               small client-side TypeScript (theme, nav, filter, contact form)
├── styles/                tokens.css (colours, spacing) + global.css

public/                    copied as-is: favicon, touch icon, cv/

```

## Common tasks

**Add a project:** create `src/content/projects/<slug>.md`. Copy an existing file's frontmatter.
The build fails with a clear message if a required field is missing or misspelled.

- `category`: `ml` | `analytics` | `bi`
- `icon`: one of the names in `src/lib/icons.ts`
- `order`: position on the Work page (1 = first)
- `featured: true`: full-width card · `showOnHome: true`: appears on the home page
- `status: in-progress`: shows a badge (and "Currently building" in the hero)
- `metric`: the real evaluation metric, e.g. `{ name: R², value: '0.87', note: 5-fold CV }`
- `repo`, `demo`: optional links

**Turn a project into a case study:** add a `caseStudy:` block (headline, facts, results) and write
the case study as the Markdown body. The page appears at `/projects/<slug>/`.

**Publish an article:** add `src/content/writing/<slug>.md` and set `draft: false`. The Writing page
and its nav link appear automatically once one post is published.

**Add your photo:** save a portrait (about 5:6) as `src/assets/profile.jpg`. Astro resizes it and serves
WebP automatically. Until then the hero shows your initials.

**Update the CV:** replace `public/cv/emmanuel-paddy-adams-cv.pdf` (same filename).

**Turn on analytics:** create a free [GoatCounter](https://www.goatcounter.com) site and put its code in
`goatcounter` in `src/config/site.ts`.

**Custom domain later:** add `public/CNAME` containing the domain, set it in the repo's Pages
settings, and change `site` in `astro.config.mjs`.

## Quality and security

- **Content validation:** Zod schemas in `src/content.config.ts`.
- **CI on every PR** (`.github/workflows/ci.yml`): Prettier, `astro check`, build, broken-link check
  (lychee), and Lighthouse budgets (performance ≥ 90, accessibility ≥ 95, best practices ≥ 90, SEO ≥ 95).
- **Content Security Policy:** generated by Astro with hashes for every script/style. There are no inline
  handlers. CSP only applies to `npm run build` / `preview`, not `npm run dev`.
- **Privacy:** the Inter font is self-hosted (downloaded at build time), so visitors make no
  third-party requests apart from the contact form.
- **SEO:** sitemap, robots.txt, canonical URLs, JSON-LD `Person` data, and generated social-preview
  images (`src/pages/og/`).

## Workflow

1. `git switch -c <change-name>`
2. Make the change, run `npm run verify`
3. Commit, push, open a pull request: CI runs
4. Merge to `main`: the site deploys
